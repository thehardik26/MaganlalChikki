# Maganlal Chikki

A modern React e-commerce storefront for a traditional Indian sweets brand. This project is built with Vite and includes product browsing, filtering, favorites, shopping cart, and category-based pages.

## Features

- Responsive storefront layout
- Product category browsing
- Search and filter products
- Price sorting and filtering
- Wishlist/favorites management
- Shopping cart flow
- Individual product detail pages
- Redux state management
- React Query for async product data

## Tech Stack

- React
- Vite
- React Router
- Redux Toolkit
- TanStack React Query
- Tailwind CSS
- Framer Motion
- React Icons

## Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Build for Production

```bash
npm run build
```

This creates a production-ready build in the `dist` folder.
